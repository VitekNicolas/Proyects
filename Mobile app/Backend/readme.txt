# Episode Finder API

An API that identifies TV show episodes based on video frame analysis — similar to how Shazam identifies songs, but for video content.

---

## 🚀 Features

- Create and retrieve episodes with title, summary, and trivia
- Process video files to extract visual fingerprints
- Match an image frame against stored episodes
- Built with FastAPI and SQLite
- Swagger-based interactive documentation
